# Promo reel (9:16, 38 s)

`../scholarizepath-reel.mp4` (Russian) is rendered from `reel.html` and `../scholarizepath-reel-en.mp4` (English)
from `reel-en.html`. Both are frame-exact motion-design pages with the same timeline.

- Preview: open `reel.html` in a browser (it loops in real time).
- Re-render: `npm i playwright-core`, set `FF` to an ffmpeg binary, then `node cap.mjs video`
  (`REEL=reel-en node cap.mjs video` for the English version)
  (or `node cap.mjs stills 1,5,10` for single frames).
- `dots.js` is the dotted land mask for the globe, generated by `dots.mjs` from `public/data/countries-50m.json`.
